# DeviceScope

Offline Android device diagnostic toolkit for inspecting smartphone hardware, software, sensors, and system information.

## Overview

DeviceScope is an Android diagnostic application designed to help users inspect smartphone conditions, especially when buying, selling, or troubleshooting used devices.

The application is designed to work offline without requiring an account, backend server, or internet connection for its core diagnostic functions.

## Planned Features

- Device information
- Software inspection
- Battery information
- Display testing
- Touchscreen testing
- Sensor diagnostics
- Camera testing
- Audio testing
- Connectivity inspection
- Diagnostic summary and reports

## Diagnostic Status

Each diagnostic result will use one of these statuses:

- PASS
- WARNING
- FAIL
- NOT TESTED
- NOT SUPPORTED

DeviceScope will only report results that can actually be verified through available Android APIs or user-performed tests.
